# Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/abdulrhmanG-alahmadi/triagekit-oss/security/advisories/new) for security issues. Include the affected commit, reproduction steps using synthetic tickets, and the expected impact. Keep exploitable details out of public issues until a fix is available.

Test only deployments you own or have permission to assess. Do not include customer data, API keys or database credentials in a report. The [model boundary and limitations](README.md#model-boundary) describe the protection TriageKit currently provides.
